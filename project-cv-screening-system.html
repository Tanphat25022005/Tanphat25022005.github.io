CV-Screening-System

Recruitment platform where HR posts jobs, candidates upload CVs, and a Python AI worker parses, scores and ranks applicants against the job description — processed asynchronously through a message queue on AWS S3 + SQS.

Key features

  • React + TypeScript frontend, Spring Boot 3 backend secured with JWT and documented with OpenAPI
  • Python AI worker parses PDF/DOCX CVs and scores candidates against each job description
  • Asynchronous pipeline on AWS S3 + SQS (MinIO + ElasticMQ locally), PostgreSQL 16
  • Docker Compose for local infrastructure, GitHub Actions for CI
